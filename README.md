# Doodle VPN for Android

Official standalone Android APK releases. This repository contains release artifacts and public metadata only.

Download the latest stable APK from [Releases](https://github.com/Simpix/doodleray-android-releases/releases/latest). No APK has been published yet.

The app can notify you when a newer stable version is available. Choose Update, download the APK, then confirm installation in Android. Updates keep the same application identity and signing certificate. Google Play builds use their own store update flow.

Application source code is maintained separately. Test and debug builds are not published here.
